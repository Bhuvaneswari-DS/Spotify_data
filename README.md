# Spotify_data

🎵 Spotify 2024 Music Dataset
This dataset contains comprehensive information on songs released or trending on Spotify in 2024. It is ideal for exploring musical trends, artist popularity, and audio feature analysis using tools like Python, Pandas, and Streamlit.

📁 Dataset Overview
Total Records: 1,091 songs

Year Covered: 2024

File Format: CSV

📌 Key Columns
track_name: Name of the song

artist_name: Performing artist(s)

popularity: Popularity score on Spotify (0–100)

duration_ms: Duration of the track in milliseconds

explicit: Whether the song is explicit (1) or not (0)

danceability, energy, valence: Audio features describing the mood and rhythm

tempo: Beats per minute

genre: Primary genre of the track

release_date: Official release date

📈 Example Use Cases
Discover the most popular artists and tracks of 2024

Analyze trends across genres and audio features

Create visualizations of musical properties like energy, tempo, and danceability

Build recommendation systems or music classifiers
